# .github

This repo holds the shared defaults for the GitHub organization of Georgetown McCourt School's Massive Data Institute. GitHub shows a file from this repo in every MDI repo that has no file of the same type of its own, so an edit here applies to all of them at once. `CONTRIBUTING.md` is the org standard: how every change goes through a PR, and what must stay out of git. `.github/pull_request_template.md` is the default PR body, with a field for what changed and why and a field for how it was checked. `GLOSSARY.md` defines the terms these files use. `.github/CODEOWNERS` names the org owner as the reviewer for every file in this repo, and only the org owner can change it. The repo must stay public for GitHub to use it as the organization default, so it holds no names of partners or people, no private repo content, and no cloud or billing details.
